How to use:
1. Open index.html in a browser, or use VS Code Live Server.
2. Replace the placeholder email swapnil@example.com with your real email.
3. Add your profile photo if desired by replacing the SP avatar block in index.html.
4. Update/add project links when you have live demos or GitHub repositories.

The portfolio is responsive and designed as a job-ready personal developer/data portfolio.
